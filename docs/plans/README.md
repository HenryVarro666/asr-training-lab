# 双 H100 从零训练方案索引

**当前推荐：先选有十六天硬截止的英语离线 ASR。** 下面两份短周期方案于 2026-10-27 制定，均为计划、尚未执行；本轮没有连接 GPU、安装环境、下载语料或启动训练。ASR 默认主训练最多 50 次自然数据暴露，固定四天用于准备与最终评测；60 次仅在 Day 2 实测后预先选定。TTS 是单独的备选项目，不能与 ASR 共用同一份双卡十六天全额预算。

以 960h、30% 工程余量计算，50 次暴露需要双卡有效吞吐约≥217 秒音频/秒墙钟才能容纳于十二天主窗口；250/300 的假设情景分别约 14.4/12.7 天总时长。最终须用过滤后真实小时、稳定吞吐和已耗时重新计算，不能从 H100 型号推出必然速度。主训练到 Day 14 硬停、项目到 `T0+384h` 交付；完整 test-clean≤10%、test-other≤25% 是项目目标而非已测结果或保证。全部执行接口/适配器仍待实施，精确参数量也尚未实例化计数。

## 保留的长期扩展方案

以下原方案继续保留，包含更大的双语模型、流式任务及翻译模型，不属于十六天推荐范围。需要更长时间时再单独审查，不把原生流式、TTS 或 3B 翻译能力算作当前离线 ASR 的交付。

**状态：计划，尚未执行。日期：2026-10-27。** 本目录分别规划随机初始化的翻译LLM与ASR/TTS。保守按2×80GB、不保证NVLink、两卡独占计算；所有吞吐和时长均为待校准假设。本轮只交付方案，没有连接GPU、下载数据或启动训练，未产生新的模型质量结果。

两卡不能同时为三项任务各提供全速吞吐。语音主训练中档约45.5天；加1.15B翻译、各先导和评测，中档约68–72天；加3B翻译则约136–140天。它们是算术情景，不是交付承诺，校准或质量门失败便缩范围或停止。完整offline ASR对照中档还需另加约26天。具体定义、公式、额外预算与硬上限见[联合日程](./asr-tts-from-scratch.md#5-把语音与翻译放进同一份两卡总日程)。

建议先读各正文开头的一页决策表，再审数据许可、随机初始化边界、tiny过拟合、100–500步校准和恢复门。文中命令/配置是未实施或未验证的接口模板，不表示这些脚本已经在本仓库实现。CPU测试、进程正常退出或loss下降，都不能替代封存测试、母语翻译评审和TTS听评。

“从零”指本实验推理链的可训练参数全部随机初始化。代码结构和确定性信号处理可以复用；公开数据的上游对齐/过滤可能用过模型，需如实披露。随机声学模型接预训练vocoder、codec或冻结encoder，只能按混合路线命名，不能记作全链从零。
